## 1. 프로젝트 개요 (Project Overview)
기존 스마트팜 시스템의 단순 사후 모니터링 방식(임계치 도달 후 사후 감지)은 저온·다습 장해 발생 시 선제적 작물 방어가 불가능하며, 계측 수치와 실제 농가의 대처 행동 지침이 단절되어 있다는 치명적인 한계가 존재합니다.

본 프로젝트는 이러한 한계를 극복하기 위해 **1시간 뒤 미래 온습도 및 물리적 포차(VPD)를 선행 예보하는 ML 엔진**과, **농촌진흥청 표준 재배 지침 도메인을 밀결합한 LangChain RAG 챗봇 시스템**을 구축하여 농가에 골든타임을 확보하고 실시간 정밀 영농 액션플랜을 서빙합니다.

## 2. 시스템 아키텍처 및 작동 흐름 (System Architecture)
[원천 CSV 데이터] ➔ [Airflow 선형 보간 정제] ➔ [PostgreSQL 마스터 정보 결합]
⬇
[Gradio UI 실시간 동기화] ⬅ [LangChain RAG 프롬프트 바인딩] ⬅ [RandomForest 1시간 뒤 예측]

### 🔄 백엔드 데이터 파이프라인 (Apache Airflow 배치 레이어)
* **STEP 1 (Data Loading & Cleaning):** 대용량 기후 시계열 원천 데이터 로드 후, 센서 단절로 발생한 결측치에 대해 시계열 연속성을 보존하기 위해 **선형 보간법(`Linear Interpolation`)** 전처리 수행.
* **STEP 2 (Context Fusion):** PostgreSQL RDB 내에 적재된 '일출/일몰 시간' 및 '딸기 정식일 마스터 정보'를 측정 타임스탬프와 1:1로 매칭하여 영농 컨텍스트 데이터 유도.
* **STEP 3 (Predict Engine):** 대기과학 검증식인 *Tetens 포화수증기압 공식*을 가동하여 내부 VPD 피처를 연산하고, **RandomForest Regressor** 알고리즘을 통해 1시간 뒤의 내부 온도, 습도, VPD 예측 데이터를 계산 후 데이터마트에 상시 적재.

### 💻 프론트엔드 서빙 레이어 (Gradio & RAG 인터랙션 레이어)
* **STEP 4 (On-Demand 동기화):** 유저 대시보드 새로고침 시 무거운 ML 재학습 없이 RDB 최상단 1줄만 0.1초 만에 초고속 쿼리하여 현황판 렌더링.
* **STEP 5 (Context-Aware RAG):** 사용자가 챗봇에 질의 시, **Chroma Vector DB**에 적재된 농진청 딸기 가이드북 지식 조각과 **현재/미래 예측 기후 팩트**를 시스템 프롬프트에 동적 결합하여 환각(Hallucination)이 제로화된 실시간 기술 처방 출력.

## 4. 모델 평가지표 및 검증 성능 (Evaluation)

### 🛡️ 시계열 블록 분할 검증 (Time-Block Split)
무작위 데이터 셔플링 학습으로 발생하는 미래 정보 유출(`Data Leakage`)을 완벽하게 차단하기 위해, 매월 24일 기준(**Train: 1~24일, Test: 25일 이후**)으로 데이터를 분할하여 실증 검증을 수행했습니다.
* **내부 온도 예측 결정계수 ($R^2$):** `0.8841` 달성
* **내부 습도 예측 결정계수 ($R^2$):** `0.9512` 달성

### ⚖️ 평가지표 MAE(Mean Absolute Error)
**직관적인 도메인 해석력:** 오차를 제곱하여 왜곡하는 MSE/RMSE와 다르게 오차 단위가 실제 온도(℃), 습도(%) 수치와 정확히 1:1로 대응되어 사용자(농민)에게 직관적인 오차 정합성 보증 가능.

## 5. 데이터 분석 및 히트맵 통계 해석 (Data Analysis)

프로젝트 내부 피어슨 상관계수 행렬(Pearson's r) 통계에 기인한 환경 변수 인과관계 분석 결과는 다음과 같습니다.

| 환경 변수 | Out_T | Out_S | In_T | In_H | In_VPD |
| :--- | :---: | :---: | :---: | :---: | :---: |
| **Out_Temp** | **1.00** | 0.35 | **0.70** | -0.18 | 0.39 |
| **Out_Solar** | 0.35 | **1.00** | 0.57 | -0.43 | 0.59 |
| **In_Temp** | **0.70** | 0.57 | **1.00** | -0.27 | 0.58 |
| **In_Hum** | -0.18 | -0.43 | -0.27 | **1.00** | **-0.85** |
| **In_VPD** | 0.39 | 0.59 | 0.58 | **-0.85** | **1.00** |

* **외부 기온 ↔ 내부 기온 연동성 ($r = 0.70$):** 하우스 외기 온도가 피복재를 투과하여 내부 온도를 지배하는 최우선 선행 유도 인자임을 통계적으로 증명.
* **일사 강도 ↔ 내부 기온 상승 ($r = 0.57$):** 투과 유입되는 복사열 에너지가 주간 내부 온도를 견인하는 동적 열원임을 실증 수치로 확인.
* **내부 상대습도 ↔ 내부 물리 포차(VPD) ($r = -0.85$):** Tetens 공식을 통해 직접 가공하여 주입한 물리 변수 VPD는 내부 습도와 극히 지배적인 음의 상관관계를 수립. 이는 **"하우스 내부가 건조할수록 공기 부족 포차(VPD)가 증가하여 증산 작용이 활발해진다"는 물리 식물학적 당위성이 전처리 데이터셋 상에 노이즈 없이 완벽하게 보존**되어 학습 정확도 극대화에 기여하고 있음을 뜻함.
