## 🚀 2주차(2026-5-21~31) 진행상황: 전처리 고도화(시계열 보간) 및 머신러닝 알고리즘 리팩토링
교수님 피드백을 기반으로 데이터 유실 문제를 완벽히 해결하기 위한 Pandas 전처리 파이프라인을 구축했으며, 단순 선형 회귀 모델의 비선형 제어 예측 한계를 극복하기 위해 의사결정나무 앙상블 기법을 도입하여 인공지능 예측력을 최고 수준으로 갱신했습니다.

* **교수님 피드백 ① (Pandas 필터링 선행):** 기존에 전체 작물 데이터가 혼재된 상태에서 `dropna()`를 수행하여 딸기 데이터가 유실되던 선후 구조를 전면 개편, **'딸기' 품목을 최우선 필터링**한 후 정제를 시작하도록 로직 수정.
* **교수님 피드백 ② (시계열 선형 보간법 도입):** 데이터 손실을 유발하는 단순 행 삭제 대신 시간 흐름의 연속성을 살리는 **`interpolate(method='linear').ffill().bfill()`** 알고리즘 적용. 학습 데이터 크기가 **5만 건에서 159,187건으로 3배 이상 증가 (데이터 유실률 0%)** 🌟
* **교수님 피드백 ③ (예보 연동 피처 확정):** 미래 기상청 단기예보 API와 연동 불가능한 불필요 피처를 배제하고, 예보 연동성이 뛰어난 **`풍속_외부`**를 최종 독립 변수로 확정 융합.
* **머신러닝 모델 리팩토링 (RandomForest 기법 도입):** 내부 기온과 습도의 복잡한 비선형 관계 및 온실 제어 매커니즘을 학습하기 위해 기존 `LinearRegression`에서 **`RandomForestRegressor`로 전격 교체 및 시스템 자원 최적화 튜닝** 완료.
* **🏆 모델 성능 최종 평가 (역대 최고 성능 달성):**
  - **🌡️ 내부 온도 예측:** 결정계수 ($R^2$ Score) 기존 `0.7325 (73.2%)` ──> **`0.8221 (82.2%)` (+8.96%p 추가 상승)** 및 MAE `1.9639 °C` 달성으로 오차 범위 1도대 진입 성공!
  - **💧 내부 습도 예측:** 결정계수 ($R^2$ Score) 기존 `0.1887 (18.8%)` ──> **`0.3500 (35.0%)` (약 2배 폭등! 한계 돌파)** 🔥
* **인프라 안정화:** Airflow 인프라 환경(도커 내부 컨테이너)의 CPU/메모리 병목 및 셧다운 현상을 해결하기 위해 하이퍼파라미터(`n_estimators=30, max_depth=10, n_jobs=1`) 자원 다이어트 튜닝 및 정상 가동 성공.

## 🚀 3주차(2026-06-01~) 진행상황: 도메인 컨텍스트 확장 및 PostgreSQL 관계형 데이터베이스(RDB) 테이블 설계 (New!)
외부 날씨 기상 변수만으로는 설명하기 한계가 있었던 내부 습도 예측력($R^2$ 35%)을 온도 수준(80% 대)으로 끌어올리기 위해, 스마트팜 농가의 물리적·생물학적 환경 데이터 모델링을 위한 백엔드 데이터베이스 인프라 확장 작업을 시작합니다.

* **농가 도메인 지식의 피처화 계획 수립:** 딸기 잎사귀의 호흡에 따른 수분 배출(`증산 작용`)과 농민의 환기창 개폐 타이밍을 인공지능에게 주입하기 위한 핵심 파라미터 도출.
* **PostgreSQL 신규 테이블 구조 정의 (DDL 설계):**
  - **`farm_crop_context` (생육 및 정식일 테이블):** 작물 품목(`딸기`), 땅에 심은 날짜(`정식일`), 현재 생육 단계(`정식기/개화기/수확기`)를 관리하여 작물의 나이와 크기(DAT)에 따른 수분 예측 기반 마련.
  - **`sun_time_context` (일출몰 시간 테이블):** 날짜별 정확한 `일출 시간` 및 `일몰 시간` 데이터를 조인하여, 낮과 밤의 전환기(창문 제어 타이밍)에 발생하는 급격한 습도 변동성을 제어.
* **데이터 파이프라인 조인(Join) 아키텍처 구상:** Airflow가 기상청 데이터를 긁어올 때, 위 두 테이블에서 오늘 날짜 기준의 생육 단계와 일출몰 데이터를 `SELECT`하여 머신러닝 독립 변수(X) 레이어에 동적으로 융합(Join)하는 백엔드 데이터 흐름 기획 중.
